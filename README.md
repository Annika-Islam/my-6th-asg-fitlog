  # 🏋️ FitLog — Workout Library

A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## 🔗 Live Link
[FitLog Live](https://your-vercel-url.vercel.app)

## 🛠️ Technologies Used
- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- React Context API
- React Hot Toast
- Lucide React Icons

## ✨ Key Features
1. Browse 12+ workouts in a responsive 3-column grid
2. Workout details page with specs and step-by-step instructions
3. Add to Today's Plan (max 5) with live metrics
4. Save for Later + Sort by Duration / Calories / Rating
5. Search workouts by name or muscle group
